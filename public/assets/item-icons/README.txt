Same idea as hero-icons/README.txt, but for equipment items (e.g. items
shown in a player's build during a match).

File naming rule: lowercase the item's name, replace spaces/punctuation
with a single hyphen, save as .png

Examples:
  Blade of Despair -> blade-of-despair.png
  Genius Wand      -> genius-wand.png
  Magic Shoes      -> magic-shoes.png
