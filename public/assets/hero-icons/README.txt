Drop hero portrait images here to have them show up automatically in the
Match Schedule hero-pick view — no admin upload needed for anything you put
in this folder.

File naming rule: lowercase the hero's name, replace spaces/apostrophes/
periods/any punctuation with a single hyphen, save as .png

Examples:
  Miya            -> miya.png
  Yu Zhong        -> yu-zhong.png
  X.Borg          -> x-borg.png
  Popol and Kupa  -> popol-and-kupa.png
  Chip            -> chip.png

If a file with the right name is found here, it's used. If not, the site
falls back to whatever's in the admin-uploaded icon library (Manage from
inside a match's hero-pick view), and if that's empty too, a plain initials
badge is shown. Nothing breaks if this folder is empty or only partially
filled in.
